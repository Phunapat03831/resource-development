# เอกสารโครงงาน

อ่านตามลำดับนี้เพื่อเข้าใจงาน:

1. [ผลวิเคราะห์หลัก](RESULTS.md) — วิธี matched pairs, จำนวนตัวอย่าง, ผลทดสอบ และข้อจำกัด
2. [พจนานุกรมข้อมูล](DATA_DICTIONARY.md) — ความหมาย หน่วย และ Series Code ของตัวแปร WDI
3. [บันทึกกระบวนการ](PROJECT_LOG.md) — ที่มาของการตัดสินใจ ปัญหาที่พบ และการแก้ไข
4. [ร่างแผนวิเคราะห์](PROPOSAL_DRAFT.md) — บันทึกการปรับวิธีหลังข้อเสนอแนะอาจารย์ ไม่ใช่ proposal ฉบับที่ส่งแล้ว

คำแนะนำสำหรับการรันสคริปต์และโครงสร้างไฟล์อยู่ใน [คู่มือโครงงาน](../README.md) ส่วนไฟล์ที่ควรดูเป็นอันดับแรกในชุดข้อมูลอยู่ใน [คำอธิบายข้อมูลประมวลผลแล้ว](../data/processed/README.md)
