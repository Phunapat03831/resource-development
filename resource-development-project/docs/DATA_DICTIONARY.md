# ตัวแปรและการเตรียมข้อมูล

## แหล่งข้อมูลและช่วงปี

ข้อมูลมาจาก World Bank, World Development Indicators (WDI) ชุด CSV ต้นทางมีหัวคอลัมน์ปี 1960–2025 แต่ตัวแปรสองตัวที่ใช้มีข้อมูลครบพร้อมกันตั้งแต่ปี 1970 ถึง 2021

| ตัวแปร | WDI Series Code | ความหมาย |
|---|---|---|
| Total natural resources rents (% of GDP) | `NY.GDP.TOTL.RT.ZS` | มูลค่า resource rents รวมเทียบกับขนาด GDP ของประเทศในปีนั้น เป็นร้อยละ ไม่ใช่ปริมาณสำรองทรัพยากรใต้ดิน |
| GDP per capita growth (annual %) | `NY.GDP.PCAP.KD.ZG` | อัตราการเติบโตของ GDP ต่อหัวในปีนั้น เป็นร้อยละ |

## หน่วยข้อมูลและการคัดเลือก

- ข้อมูลต้นทางเป็นประเทศ/เขตเศรษฐกิจ × ปี; รวมตัวแปรด้วยรหัสหน่วยและปี
- ใช้รายชื่อ 217 หน่วยใน `data/processed/country_list_to_review.csv` เพื่อคัดกลุ่มภูมิภาค กลุ่มรายได้ และแถวสรุปอื่นออก
- ใช้เฉพาะแถวที่ rents และ GDP per capita growth มีค่าทั้งคู่ ไม่แทนค่าที่หาย
- มีข้อมูลร่วม 4,460 ประเทศ–ปีในช่วงหลัก 2000–2021 และ 9,021 ประเทศ–ปีในช่วงยาวที่ข้อมูลร่วมมีจริง 1970–2021

## วิธีจับคู่

คำนวณจุดตัดเปอร์เซ็นไทล์ที่ 33 และ 67 ของ rents แยกภายในแต่ละประเทศในแต่ละช่วงวิเคราะห์ โดยใช้ linear interpolation:

1. rents ไม่เกินจุดตัดเปอร์เซ็นไทล์ 33 จัดเป็นช่วงต่ำ
2. rents ไม่น้อยกว่าจุดตัดเปอร์เซ็นไทล์ 67 จัดเป็นช่วงสูง
3. ตัดค่าที่อยู่ระหว่างสองจุดตัดออก และต้องมีอย่างน้อย 3 ปีในแต่ละช่วง
4. หาค่าเฉลี่ย GDP per capita growth ของช่วงต่ำและสูง แล้วคำนวณหนึ่งผลต่างต่อประเทศ

ผลต่างของประเทศ i คือ:

    dᵢ = ค่าเฉลี่ย growth ในปี rents สูง − ค่าเฉลี่ย growth ในปี rents ต่ำ

แต่ละประเทศมีน้ำหนักเท่ากันเมื่อหาค่าเฉลี่ยของผลต่าง

## การทดสอบ

การทดสอบหลักเป็น paired t-test แบบสองด้าน:

    H₀: μd = 0
    H₁: μd ≠ 0
    t = d̄ / (sᵈ / √n),  df = n − 1

โดย n คือจำนวนประเทศ/เขตเศรษฐกิจที่มีคู่ข้อมูล ซึ่งเท่ากับ 189 ไม่ใช่จำนวนประเทศ–ปี ใช้ Wilcoxon signed-rank test เป็นการตรวจสอบเสริมจากอันดับของผลต่าง การตีความแบบตำแหน่งกึ่งกลางของ Wilcoxon ต้องพิจารณาความสมมาตรของผลต่างด้วย
