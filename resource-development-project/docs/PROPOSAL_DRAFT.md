# ร่างแผนวิเคราะห์ฉบับปรับตามคำแนะนำอาจารย์

เอกสารนี้เป็นบันทึกวิธีวิเคราะห์สำหรับทำรายงานและนำเสนอหลังได้รับคำแนะนำให้ใช้วิธีทางสถิติที่เรียนในวิชา โดยใช้ matched-pairs t-test เป็นวิธีหลัก ร่างนี้ไม่ได้แทน proposal ฉบับที่ส่งไปแล้ว

## 1. คำถามวิจัย

ภายในประเทศหรือเขตเศรษฐกิจเดียวกัน การเติบโตของ GDP ต่อหัวเฉลี่ยแตกต่างกันหรือไม่ ระหว่างปีที่มีสัดส่วนค่าเช่าทรัพยากรธรรมชาติต่อ GDP ต่ำกับปีที่มีสัดส่วนดังกล่าวสูง?

- **H0:** ผลต่างเฉลี่ยระหว่างปี rents สูงกับปี rents ต่ำเท่ากับศูนย์
- **H1:** ผลต่างเฉลี่ยระหว่างปี rents สูงกับปี rents ต่ำไม่เท่ากับศูนย์
- กำหนดระดับนัยสำคัญไว้ที่ 5% และใช้การทดสอบสองด้าน

ผลต่างของแต่ละคู่คำนวณเป็น `ค่าเฉลี่ย GDP per capita growth ในกลุ่ม rents สูง − ค่าเฉลี่ยในกลุ่ม rents ต่ำ` ภายในหน่วยประเทศ/เศรษฐกิจเดียวกัน

## 2. แรงจูงใจและตัวแปรหลัก

แนวคิด resource curse ตั้งคำถามว่าการพึ่งพารายได้จากทรัพยากรธรรมชาติมากสัมพันธ์กับผลลัพธ์ทางเศรษฐกิจอย่างไร ในงานนี้ `Total natural resources rents (% of GDP)` ใช้แทนระดับการพึ่งพารายได้จากทรัพยากรโดยประมาณ ตัวแปรนี้ไม่ใช่ปริมาณสำรองหรือความอุดมสมบูรณ์ของทรัพยากรใต้ดิน

ผลลัพธ์หลักคือ `GDP per capita growth (annual %)`. ข้อมูลมาจาก World Development Indicators (WDI) ของ World Bank ในช่วงปี 2000–2021 ตัวแปรเสริม เช่น GDP growth, poverty gap, Gini index และ political stability มีในชุดข้อมูล แต่ไม่ใช่ผลทดสอบหลักของการวิเคราะห์ matched pairs รอบนี้

## 3. ข้อมูลและกระบวนการจับคู่

หน่วยข้อมูลต้นทางคือประเทศ/เขตเศรษฐกิจต่อปี รวมข้อมูลด้วย Country Code และ Year และตัดแถวกลุ่มภูมิภาคหรือกลุ่มรายได้ที่ไม่ใช่หน่วยเดี่ยว ไม่เติมค่าที่หายไป การเปรียบเทียบหลักใช้เฉพาะปีที่มีข้อมูลทั้ง resource rents และ GDP per capita growth

สำหรับแต่ละประเทศ/เขตเศรษฐกิจ:

1. คำนวณเปอร์เซ็นไทล์ที่ 33 และ 67 ของ resource rents จากปีที่ข้อมูลครบ
2. กำหนดปีที่ rents ไม่เกินเปอร์เซ็นไทล์ 33 เป็นกลุ่มต่ำ และปีที่ rents ไม่น้อยกว่าเปอร์เซ็นไทล์ 67 เป็นกลุ่มสูง; ไม่ใช้ปีช่วงกลาง
3. ต้องมีอย่างน้อย 3 ปีในแต่ละกลุ่ม และจุดตัดกลุ่มต่ำ/สูงต้องแตกต่างกัน
4. หาค่าเฉลี่ย GDP per capita growth ของกลุ่มต่ำและกลุ่มสูง แล้วคำนวณผลต่างสูงลบต่ำ
5. ใช้ผลต่างหนึ่งค่าต่อประเทศ/เขตเศรษฐกิจเป็นหนึ่งคู่ในการทดสอบ

จาก panel 217 หน่วย มีข้อมูลของสองตัวแปรพร้อมกัน 4,460 country-years; 5 หน่วยไม่มีปีข้อมูลที่ใช้จับคู่ได้ ใน 212 หน่วยที่เหลือ หน่วยที่จุดตัดต่ำและสูงแยกกันไม่ได้ 22 หน่วย และอีก 1 หน่วยมีจำนวนปีไม่พอ จึงเหลือ 189 คู่ การทดสอบให้น้ำหนักแต่ละคู่เท่ากัน

## 4. วิธีทางสถิติ

ใช้ **paired-samples t-test** ทดสอบว่าค่าเฉลี่ยของผลต่าง 189 คู่แตกต่างจากศูนย์หรือไม่ วิธีนี้เหมาะกับข้อมูลที่แต่ละประเทศมีค่าผลลัพธ์สองค่า คือค่าเฉลี่ยในกลุ่ม rents ต่ำและกลุ่ม rents สูง ซึ่งเชื่อมโยงกันเพราะมาจากประเทศเดียวกัน

รายงานค่าเฉลี่ยทั้งสองกลุ่ม ผลต่างเฉลี่ย ส่วนเบี่ยงเบนมาตรฐานของผลต่าง ช่วงความเชื่อมั่น 95% ค่า t, p-value และจำนวนคู่ ใช้ **Wilcoxon signed-rank test** เป็นการตรวจสอบเพิ่มเติมว่าข้อสรุปเชิงทิศทางยังสอดคล้องหรือไม่เมื่อใช้วิธีจัดอันดับของผลต่าง

## 5. ผลเบื้องต้น

| ผล | ค่า |
|---|---:|
| จำนวนคู่ประเทศ/เขตเศรษฐกิจ | 189 |
| ค่าเฉลี่ยรายประเทศ ช่วง rents ต่ำ | 1.416% |
| ค่าเฉลี่ยรายประเทศ ช่วง rents สูง | 2.642% |
| ผลต่างเฉลี่ย (สูง − ต่ำ) | 1.226 จุดเปอร์เซ็นต์ |
| ช่วงความเชื่อมั่น 95% | 0.673 ถึง 1.779 จุดเปอร์เซ็นต์ |
| Paired t-test, t(188) | 4.373 |
| p-value แบบสองด้าน | 0.000020 |
| Wilcoxon signed-rank p-value | 0.000011 |

เนื่องจาก p-value ของ paired t-test ต่ำกว่า 0.05 และช่วงความเชื่อมั่นไม่คร่อมศูนย์ จึงปฏิเสธ H0 สำหรับข้อมูลและเกณฑ์การจัดกลุ่มชุดนี้ กล่าวโดยง่าย ค่าเฉลี่ยการเติบโตต่อหัวในกลุ่มปี rents สูงมากกว่ากลุ่มปี rents ต่ำประมาณ 1.23 จุดเปอร์เซ็นต์ เมื่อเทียบค่าเฉลี่ยภายในแต่ละหน่วยประเทศ/เศรษฐกิจ

ผลนี้ไม่ได้หมายความว่า resource rents เพิ่ม 1 จุดเปอร์เซ็นต์แล้ว GDP ต่อหัวเติบโตเพิ่ม 1.23 จุดเปอร์เซ็นต์ และไม่ได้พิสูจน์ว่า rents เป็นสาเหตุของการเติบโต ผลจาก Wilcoxon ให้ค่า p-value ต่ำกว่า 0.05 เช่นกัน จึงสนับสนุนว่าทิศทางผลไม่ขึ้นกับการใช้ paired t-test เพียงอย่างเดียว

## 7. กราฟสำหรับอธิบายผล

กราฟหลักแสดงผลต่างของค่าเฉลี่ย GDP per capita growth ของแต่ละคู่ จุดหนึ่งจุดแทนหนึ่งประเทศ/เขตเศรษฐกิจ เส้นประแนวนอนหมายถึงผลต่างเป็นศูนย์ แถบสีแสดงช่วงความเชื่อมั่น 95% ของผลต่างเฉลี่ย

กราฟกระจายและกราฟ regression ที่ทำก่อนหน้านี้เก็บไว้ในโฟลเดอร์ผลเดิมเพื่อใช้เป็นข้อมูลสำรวจหรือภาคผนวก ไม่ควรนำเสนอเป็นผลหลักหลังปรับวิธี

## 8. ข้อจำกัด

- กลุ่มสูงและต่ำเป็นการจัดอันดับภายในแต่ละประเทศ จึงเทียบช่วงสัมบูรณ์เดียวกันข้ามประเทศไม่ได้
- การตัดกลุ่มกลางออกทำให้ไม่ได้ใช้ทุกปี และต้องอาศัยเกณฑ์เปอร์เซ็นไทล์ที่กำหนดไว้
- การจับคู่ช่วยเทียบแต่ละประเทศกับตัวเองและลดอิทธิพลจากลักษณะที่คงที่ของประเทศ แต่ไม่ได้ควบคุมเหตุการณ์ร่วมในแต่ละปีหรือปัจจัยที่เปลี่ยนตามเวลา เช่น ภาวะเศรษฐกิจโลก
- Resource rents วัดเป็นสัดส่วนต่อ GDP ตัวหาร GDP อาจทำให้ตัวชี้วัดเปลี่ยนจากทั้งรายได้ทรัพยากรและขนาด GDP
- ข้อมูลเป็นข้อมูลสังเกตการณ์ จึงสรุปความเป็นเหตุและผลไม่ได้
- poverty gap และ Gini มีข้อมูลน้อยกว่าตัวแปรเศรษฐกิจ จึงเหมาะเป็นผลเสริมที่ต้องระบุขนาดตัวอย่างให้ชัด
