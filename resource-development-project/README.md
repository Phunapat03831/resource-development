# Resource Dependence and Development Outcomes

โครงงานกลุ่มนี้ศึกษาว่า **การพึ่งพารายได้จากทรัพยากรธรรมชาติสัมพันธ์กับการเติบโตทางเศรษฐกิจและผลลัพธ์ด้านการพัฒนาอย่างไร** โดยใช้ข้อมูลรายประเทศ/เขตเศรษฐกิจจาก World Development Indicators (WDI) ของธนาคารโลก ช่วงปี 2000–2021

> สถานะปัจจุบัน: รวมข้อมูลและตรวจคุณภาพแล้ว วิเคราะห์ regression เบื้องต้นและแบบจำลองควบคุมสำหรับ GDP ต่อหัวแล้ว และมีร่าง proposal พร้อมกราฟประกอบ ผลชี้ถึงความสัมพันธ์ทางสถิติ ไม่ได้พิสูจน์เหตุและผล รายงานฉบับสุดท้ายและสไลด์ยังต้องจัดทำและตรวจตาม rubric รายวิชา

โจทย์รายวิชากำหนด proposal วันที่ 5 ตุลาคม 2026, การนำเสนอ 10 นาทีในสัปดาห์ก่อนสอบปลายภาค และรายงานฉบับสุดท้ายวันที่ 13 ธันวาคม 2026 รายละเอียดคะแนนฉบับเต็มอยู่ใน alternative syllabus ซึ่งยังไม่ได้รวมไว้ใน repository นี้

## คำถามวิจัย

1. เมื่อสัดส่วนค่าเช่าทรัพยากรธรรมชาติต่อ GDP เปลี่ยนไปภายในประเทศเดียวกัน การเติบโตของ GDP ต่อหัวเปลี่ยนไปสัมพันธ์กันอย่างไร?
2. ความสัมพันธ์ระหว่างค่าเช่าทรัพยากรกับการเติบโตของ GDP ต่อหัวคงอยู่หรือไม่ เมื่อควบคุมรายได้ต่อหัวในปีก่อนและการเติบโตของประชากร?
3. ค่าเช่าทรัพยากรในปีก่อนสัมพันธ์กับการเติบโตของ GDP ต่อหัวในปีปัจจุบันหรือไม่?
4. ค่าเช่าทรัพยากรสัมพันธ์กับช่องว่างความยากจน ความเหลื่อมล้ำทางรายได้ และเสถียรภาพทางการเมืองหรือไม่?
5. ความสัมพันธ์แตกต่างกันหรือไม่เมื่อพิจารณาค่าเช่าจากน้ำมัน ก๊าซ ถ่านหิน แร่ และป่าไม้แยกกัน? **ข้อนี้เป็นแนววิเคราะห์เพิ่มเติมที่ยังไม่ได้ประมาณผลในปัจจุบัน**

## แรงจูงใจและกรอบคิด

แนวคิด resource curse ตั้งคำถามว่าประเทศที่พึ่งพารายได้จากทรัพยากรธรรมชาติมากอาจเผชิญผลลัพธ์ทางเศรษฐกิจและสังคมที่ซับซ้อน เช่น ความผันผวนของรายได้ การกระจุกตัวของเศรษฐกิจ หรือความท้าทายด้านสถาบัน โครงงานจึงเปรียบเทียบตัวชี้วัดด้านการเติบโต ความยากจน ความเหลื่อมล้ำ และเสถียรภาพทางการเมือง

ตัวแปร `total_resource_rents_pct_gdp` วัด **สัดส่วนค่าเช่าทรัพยากรธรรมชาติต่อ GDP** จึงใช้แทนระดับการพึ่งพาทรัพยากรในเศรษฐกิจ ไม่ใช่ปริมาณทรัพยากรใต้ดินหรือความอุดมสมบูรณ์ทางกายภาพ

## ภาพรวมผลเบื้องต้น

แบบจำลองควบคุมหลักใช้ GDP ต่อหัวของปีก่อน (ลอการิทึมธรรมชาติ) และการเติบโตของประชากร พร้อม fixed effects ของประเทศและปี และ standard errors ที่จัดกลุ่มตามประเทศ

| แบบจำลอง | สัมประสิทธิ์ของ resource rents (% GDP) | p-value | ประเทศ-ปี |
|---|---:|---:|---:|
| Baseline บนตัวอย่างที่มีตัวแปรควบคุมหลักครบ | 0.147 | 0.0014 | 4,251 |
| ควบคุม GDP ต่อหัวปีก่อนและการเติบโตของประชากร | 0.158 | 0.0061 | 4,251 |
| เพิ่มการลงทุนและการค้า | 0.197 | 0.0006 | 3,503 |
| Resource rents ปีก่อน ในตัวอย่างเปรียบเทียบ lag | 0.066 | 0.2460 | 4,243 |

ในแบบจำลองควบคุมหลัก สัมประสิทธิ์ 0.158 หมายถึงเมื่อ resource rents เพิ่มขึ้น 1 จุดเปอร์เซ็นต์ของ GDP การเติบโตของ GDP ต่อหัวสัมพันธ์กับค่าที่สูงขึ้นประมาณ 0.158 จุดเปอร์เซ็นต์ ภายใต้ตัวแปรควบคุมและ fixed effects ในแบบจำลองนี้ ผลเป็นความสัมพันธ์ ไม่ใช่ข้อสรุปว่า resource rents ทำให้การเติบโตเพิ่มขึ้น

แบบจำลองที่เพิ่มการลงทุนและการค้าเหลือ 183 ประเทศ เนื่องจากข้อมูลบางประเทศขาดหาย และตัวแปรทั้งสองอาจเป็นช่องทางที่ resource rents เชื่อมโยงกับการเติบโตได้ จึงรายงานเป็นแบบจำลองเสริม ไม่ใช้แทนผลหลัก รายละเอียดและผลลัพธ์ตัวแปรอื่นอยู่ใน [`docs/RESULTS.md`](docs/RESULTS.md)

## กระบวนการทำงาน

1. เก็บ workbook ต้นฉบับ `data.xlsx` และ `adddata.xlsx` ไว้ใน `data/raw/` เพื่อให้ตรวจย้อนกลับได้
2. อ่านตาราง WDI แบบกว้างที่มีหนึ่งคอลัมน์ต่อปี เลือกตัวแปรด้วย Series Code แล้วแปลงเป็นรูปแบบ country-year
3. แปลงเครื่องหมายข้อมูลว่าง เช่น `..` เป็น missing value โดยไม่แทนด้วยศูนย์หรือค่าประมาณ
4. กรองแถวภูมิภาค กลุ่มรายได้ และยอดรวมที่ไม่ใช่ประเทศ/เขตเศรษฐกิจเดี่ยว
5. รวมข้อมูลด้วย `Country Code` และ `Year` และตรวจความซ้ำของ country-year
6. สร้างชุดข้อมูลรวมและชุด complete-case แยกตามผลลัพธ์ ตัวอย่างที่ใช้จึงมีจำนวนประเทศ-ปีต่างกันตามข้อมูลที่มี
7. ประมาณ regression แบบ country และ year fixed effects พร้อม standard errors ที่จัดกลุ่มตามประเทศ
8. เปรียบเทียบผล resource rents ปีปัจจุบันกับปีก่อน และเปรียบเทียบแบบจำลองควบคุมหลักกับแบบขยาย

ไม่มีการเติมข้อมูลที่ขาดด้วยการประมาณค่า ผลของแต่ละโมเดลจึงใช้เฉพาะแถวที่มีข้อมูลครบตามตัวแปรของโมเดลนั้น

ใช้ Python 3.10 ขึ้นไป จากโฟลเดอร์หลักของโปรเจกต์:

## ข้อจำกัดที่ควรกล่าวถึง

- ค่าเช่าทรัพยากรคิดเป็นสัดส่วนต่อ GDP ตัวหาร GDP ทำให้ตัวชี้วัดเปลี่ยนได้จากทั้งรายได้ทรัพยากรและ GDP
- Fixed effects ช่วยควบคุมลักษณะประเทศที่คงที่และเหตุการณ์ร่วมรายปี แต่ไม่ได้กำจัดตัวแปรกวนที่เปลี่ยนตามเวลา หรือปัญหาเหตุและผลย้อนกลับ
- poverty gap และ Gini มีข้อมูลน้อยกว่าตัวแปรเศรษฐกิจมาก ผลของสองตัวนี้จึงใช้ตัวอย่างเล็กกว่า
- แบบจำลองที่เพิ่มการลงทุนและการค้าใช้ตัวอย่างต่างจากแบบหลัก และการลงทุน/การค้าอาจเป็นกลไกผ่านกลาง
- ผลจากค่าเช่ารวมยังไม่บอกว่าทรัพยากรชนิดใดเป็นตัวขับผล คำถามเรื่องแยกชนิดทรัพยากรยังเป็นงานต่อไป
- สถานะปัจจุบันยังไม่ใช่รายงานฉบับส่ง ต้องตรวจ rubric ฉบับละเอียดใน alternative syllabus ก่อนจัดรูปแบบ final report และ presentation
