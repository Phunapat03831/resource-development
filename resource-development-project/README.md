# คู่มือโครงงาน

โครงงานนี้ใช้ข้อมูล WDI ปี 2000–2021 ศึกษาความแตกต่างของการเติบโต GDP ต่อหัวระหว่างช่วงที่ resource rents ต่ำและสูง **ภายในประเทศเดียวกัน**

## คำถามหลัก

ในประเทศ/เขตเศรษฐกิจเดียวกัน ค่าเฉลี่ย GDP per capita growth ต่างกันหรือไม่ ระหว่างปีที่ resource rents อยู่ในกลุ่มต่ำกับกลุ่มสูง?

## วิธีวิเคราะห์

1. รวมข้อมูล WDI ด้วยรหัสประเทศและปี ตัดข้อมูลกลุ่มรวม และไม่เติมค่าที่หายไป
2. ในแต่ละประเทศ เรียงปีที่มีข้อมูล rents และ growth ครบตามระดับ rents แล้วจัดหนึ่งในสามล่างเป็นกลุ่มต่ำ และหนึ่งในสามบนเป็นกลุ่มสูง; ไม่ใช้ช่วงกลาง
3. ต้องมีอย่างน้อย 3 ปีในแต่ละกลุ่ม แล้วคำนวณค่าเฉลี่ย GDP per capita growth ของกลุ่มต่ำและสูง
4. หาผลต่างรายประเทศ (สูง − ต่ำ) แล้วทดสอบค่าเฉลี่ยผลต่าง 189 คู่ด้วย paired t-test
5. ใช้ Wilcoxon signed-rank เป็นการตรวจสอบเพิ่มเติม

## ผลหลัก

| รายการ | ผล |
|---|---:|
| คู่ประเทศ/เขตเศรษฐกิจ | 189 |
| ค่าเฉลี่ยช่วง rents ต่ำ | 1.416% |
| ค่าเฉลี่ยช่วง rents สูง | 2.642% |
| ผลต่างเฉลี่ย | +1.226 จุดเปอร์เซ็นต์ |
| 95% CI | +0.673 ถึง +1.779 |
| Paired t-test | t(188) = 4.373, p = 0.000020 |
| Wilcoxon signed-rank | p = 0.000011 |

การเปรียบเทียบให้น้ำหนักแต่ละประเทศเท่ากัน เป็นความสัมพันธ์จากข้อมูลสังเกตการณ์ จึงไม่ยืนยันว่า rents เป็นสาเหตุของการเติบโต และไม่ได้ควบคุมเหตุการณ์ร่วมในแต่ละปี

## ทำซ้ำการวิเคราะห์หลัก

เปิด PowerShell ที่โฟลเดอร์ resource-development-project แล้วรัน:

    python -m pip install -r requirements.txt
    python prepare_resource_data.py
    python merge_additional_wdi.py
    python quick_check.py
    python matched_pairs.py

ไฟล์ต้นทางที่ใช้ต้องอยู่ใน data/raw/data.xlsx และ data/raw/adddata.xlsx
