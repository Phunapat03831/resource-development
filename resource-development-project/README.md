# Resource Dependence and Development Outcomes

โครงงานกลุ่มนี้ศึกษาว่า **การพึ่งพารายได้จากทรัพยากรธรรมชาติสัมพันธ์กับการเติบโตทางเศรษฐกิจและผลลัพธ์ด้านการพัฒนาอย่างไร** โดยใช้ข้อมูลรายประเทศ/เขตเศรษฐกิจจาก World Development Indicators (WDI) ของธนาคารโลก ช่วงปี 2000–2021

> สถานะปัจจุบัน: หลังรับข้อเสนอแนะจากอาจารย์ วิธีหลักปรับเป็นการเปรียบเทียบแบบจับคู่ (matched-pairs t-test) ซึ่งใช้เนื้อหาที่เรียนในวิชาแล้ว ผล regression ที่ทำก่อนหน้านี้เก็บไว้เป็นการวิเคราะห์สำรวจ ไม่ใช้เป็นผลหลักของฉบับนี้ ผลทั้งหมดเป็นความสัมพันธ์ ไม่ใช่หลักฐานเหตุและผล รายงานฉบับสุดท้ายและสไลด์ยังต้องจัดทำตาม rubric รายวิชา

โจทย์รายวิชากำหนด proposal วันที่ 5 ตุลาคม 2026, การนำเสนอ 10 นาทีในสัปดาห์ก่อนสอบปลายภาค และรายงานฉบับสุดท้ายวันที่ 13 ธันวาคม 2026 รายละเอียดคะแนนฉบับเต็มอยู่ใน alternative syllabus ซึ่งยังไม่ได้รวมไว้ใน repository นี้

## คำถามวิจัย

1. ภายในประเทศ/เขตเศรษฐกิจเดียวกัน การเติบโตของ GDP ต่อหัวเฉลี่ยต่างกันหรือไม่ ระหว่างปีที่พึ่งพารายได้จากทรัพยากรสูงกับปีที่พึ่งพาต่ำ?
2. ผลที่พบยังไปในทิศทางเดิมหรือไม่ เมื่อใช้ Wilcoxon signed-rank ซึ่งเป็นการตรวจสอบเพิ่มเติมโดยพิจารณาลำดับของผลต่าง?

GDP growth, poverty gap, Gini, political stability และ regression ที่ควบคุมหลายตัวแปรเป็นผลสำรวจประกอบ ไม่ใช่คำถามหลักของการทดสอบ matched pairs รอบนี้

## แรงจูงใจและกรอบคิด

แนวคิด resource curse ตั้งคำถามว่าประเทศที่พึ่งพารายได้จากทรัพยากรธรรมชาติมากอาจเผชิญผลลัพธ์ทางเศรษฐกิจและสังคมที่ซับซ้อน เช่น ความผันผวนของรายได้ การกระจุกตัวของเศรษฐกิจ หรือความท้าทายด้านสถาบัน โครงงานจึงเปรียบเทียบตัวชี้วัดด้านการเติบโต ความยากจน ความเหลื่อมล้ำ และเสถียรภาพทางการเมือง

ตัวแปร `total_resource_rents_pct_gdp` วัด **สัดส่วนค่าเช่าทรัพยากรธรรมชาติต่อ GDP** จึงใช้แทนระดับการพึ่งพาทรัพยากรในเศรษฐกิจ ไม่ใช่ปริมาณทรัพยากรใต้ดินหรือความอุดมสมบูรณ์ทางกายภาพ

## ผลเบื้องต้นจาก matched pairs

แต่ละประเทศ/เขตเศรษฐกิจถูกจับคู่กับตัวเอง: หาค่าเฉลี่ยการเติบโตของ GDP ต่อหัวในช่วงที่ resource rents ของหน่วยนั้นอยู่กลุ่มต่ำ และเทียบกับค่าเฉลี่ยในช่วงกลุ่มสูง จากนั้นทดสอบผลต่างของ 189 คู่ด้วย paired t-test แบบสองทาง

| ตัวชี้วัด | ผล |
|---|---:|
| คู่ประเทศ/เขตเศรษฐกิจ | 189 |
| ค่าเฉลี่ยรายประเทศในปี rents ต่ำ | 1.42% |
| ค่าเฉลี่ยรายประเทศในปี rents สูง | 2.64% |
| ผลต่างเฉลี่ย (สูง − ต่ำ) | +1.23 จุดเปอร์เซ็นต์ |
| ช่วงความเชื่อมั่น 95% | +0.67 ถึง +1.78 จุดเปอร์เซ็นต์ |
| paired t-test, p-value | 0.000020 |
| Wilcoxon signed-rank, p-value | 0.000011 |

ที่ระดับนัยสำคัญ 5% เราปฏิเสธสมมติฐานว่าผลต่างเฉลี่ยเท่ากับศูนย์ในตัวอย่างนี้ กล่าวแบบง่ายคือ ค่าเฉลี่ยการเติบโตในประเทศเดียวกันสูงกว่าในกลุ่มปี rents สูง เมื่อเทียบกับกลุ่มปี rents ต่ำ โดยค่าเฉลี่ยของแต่ละประเทศให้น้ำหนักเท่ากัน ผลนี้ยังสรุปไม่ได้ว่า rents ทำให้การเติบโตสูงขึ้น

จัดกลุ่มต่ำ/สูงจากเปอร์เซ็นไทล์ 33 และ 67 ของ resource rents ภายในแต่ละประเทศ โดยตัดช่วงกลางออก และต้องมีข้อมูลอย่างน้อย 3 ปีในแต่ละกลุ่ม จาก 217 หน่วยใน panel มี 5 หน่วยที่ไม่มีปีใดมีข้อมูลครบทั้ง rents และ growth; ใน 212 หน่วยที่เหลือ ตัดออก 22 หน่วยเพราะค่าเปอร์เซ็นไทล์ต่ำและสูงแยกกันไม่ได้ และ 1 หน่วยเพราะมีปีข้อมูลไม่พอ จึงเหลือ 189 คู่ ผลต่างของแต่ละคู่คำนวณเป็น `ค่าเฉลี่ยช่วงสูง − ค่าเฉลี่ยช่วงต่ำ` ผล regression เดิมยังอยู่ใน [`docs/RESULTS.md`](docs/RESULTS.md) เพื่อแสดงกระบวนการสำรวจ แต่ไม่ใช่ข้อสรุปหลักของฉบับปรับวิธี

### กราฟเบื้องต้น

กราฟแสดงผลต่างของค่าเฉลี่ยภายในแต่ละประเทศ/เขตเศรษฐกิจ (ปี rents สูงลบปี rents ต่ำ) จุดละหนึ่งคู่ เส้นประคือไม่มีผลต่าง แถบสีแสดงช่วงความเชื่อมั่น 95% ของผลต่างเฉลี่ย

## กระบวนการทำงาน

1. เก็บ workbook ต้นฉบับ `data.xlsx` และ `adddata.xlsx` ไว้ใน `data/raw/` เพื่อให้ตรวจย้อนกลับได้
2. อ่านตาราง WDI แบบกว้างที่มีหนึ่งคอลัมน์ต่อปี เลือกตัวแปรด้วย Series Code แล้วแปลงเป็นรูปแบบ country-year
3. แปลงเครื่องหมายข้อมูลว่าง เช่น `..` เป็น missing value โดยไม่แทนด้วยศูนย์หรือค่าประมาณ
4. กรองแถวภูมิภาค กลุ่มรายได้ และยอดรวมที่ไม่ใช่ประเทศ/เขตเศรษฐกิจเดี่ยว
5. รวมข้อมูลด้วย `Country Code` และ `Year` และตรวจความซ้ำของ country-year
6. สร้างชุดข้อมูลรวมและชุด complete-case แยกตามผลลัพธ์ โดยไม่เติม missing values
7. สำหรับ matched pairs ใช้ปีที่มีทั้ง resource rents และ GDP per capita growth จัดปีในแต่ละประเทศเป็นกลุ่มต่ำ/สูงตามเปอร์เซ็นไทล์ 33/67 แล้วหาค่าเฉลี่ยการเติบโตของแต่ละกลุ่ม
8. คำนวณผลต่างรายประเทศ (ค่าเฉลี่ยกลุ่มสูง − ค่าเฉลี่ยกลุ่มต่ำ) แล้วทดสอบค่าเฉลี่ยผลต่าง 189 คู่นี้ด้วย paired t-test แบบสองด้านที่ระดับ 5%; ใช้ Wilcoxon signed-rank เป็น sensitivity check
9. เก็บ regression ที่ทำก่อนหน้าเป็นการวิเคราะห์สำรวจ/ภาคผนวก ไม่ใช้แทนผลหลักของวิธีจับคู่

ไม่มีการเติมข้อมูลที่ขาดด้วยการประมาณค่า ผลของแต่ละโมเดลจึงใช้เฉพาะแถวที่มีข้อมูลครบตามตัวแปรของโมเดลนั้น

## วิธีทำซ้ำ

ใช้ Python 3.10 ขึ้นไป จากโฟลเดอร์หลักของโปรเจกต์:

```powershell
python -m pip install -r requirements.txt
python prepare_resource_data.py
python merge_additional_wdi.py
python matched_pairs.py
```

สคริปต์ `regression_resource.py`, `regression_growth_robustness.py`, `regression_growth_controls.py` และ `make_figures.py` ทำซ้ำผล regression/กราฟจากระยะสำรวจเดิม ซึ่งยังเก็บไว้เป็นข้อมูลประกอบ ไม่ใช่วิธีหลักหลังปรับตามคำแนะนำอาจารย์

`quick_check.py` ใช้ตรวจจำนวนแถว country-year ซ้ำ รหัสกลุ่มรวม และช่วงค่าของตัวแปรที่ควรอยู่ระหว่าง 0–100:

```powershell
python quick_check.py
```

ไฟล์ raw และ processed ที่อยู่ใน repository เป็น snapshot ที่ใช้ทำผลในเอกสารนี้ อย่าเขียนทับไฟล์ใน `data/raw/` เมื่ออัปเดตข้อมูล ให้เก็บไฟล์ใหม่แยกหรือบันทึกวันที่ดาวน์โหลดและปรับขั้นตอนทำซ้ำให้ตรงกัน

## ข้อจำกัดที่ควรกล่าวถึง

- ค่าเช่าทรัพยากรคิดเป็นสัดส่วนต่อ GDP ตัวหาร GDP ทำให้ตัวชี้วัดเปลี่ยนได้จากทั้งรายได้ทรัพยากรและ GDP
- matched pairs เปรียบเทียบค่าเฉลี่ยช่วง rents สูง/ต่ำของประเทศเดียวกัน จึงลดอิทธิพลจากลักษณะประเทศที่คงที่ได้บางส่วน แต่ไม่ได้ควบคุมเหตุการณ์ร่วมในแต่ละปีหรือปัจจัยอื่นที่เปลี่ยนตามเวลา
- นิยามกลุ่มสูง/ต่ำเป็นแบบสัมพัทธ์ภายในแต่ละประเทศ ค่า rents สูงของประเทศหนึ่งอาจต่ำกว่าอีกประเทศหนึ่งได้ และการตัดช่วงกลางทิ้งทำให้การทดสอบไม่ได้ใช้ทุกปี
- การเติบโตเฉลี่ยของประเทศแต่ละแห่งได้รับน้ำหนักเท่ากัน ไม่ได้ถ่วงตามประชากรหรือ GDP
- poverty gap และ Gini มีข้อมูลน้อยกว่าตัวแปรเศรษฐกิจมาก ผลของสองตัวนี้จึงใช้ตัวอย่างเล็กกว่า
- แบบจำลองที่เพิ่มการลงทุนและการค้าใช้ตัวอย่างต่างจากแบบหลัก และการลงทุน/การค้าอาจเป็นกลไกผ่านกลาง
- ผลจากค่าเช่ารวมยังไม่บอกว่าทรัพยากรชนิดใดเป็นตัวขับผล คำถามเรื่องแยกชนิดทรัพยากรยังเป็นงานต่อไป
- สถานะปัจจุบันยังไม่ใช่รายงานฉบับส่ง ต้องตรวจ rubric ฉบับละเอียดใน alternative syllabus ก่อนจัดรูปแบบ final report และ presentation
