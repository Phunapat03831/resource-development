# ข้อมูลต้นทาง

ไฟล์ `wdi_growth_rents_1960_2025.csv` เป็นข้อมูลจาก World Bank, World Development Indicators (WDI) ที่ใช้ในโครงงานนี้ มีตัวแปรที่เลือกสองชุด:

- Total natural resources rents (% of GDP), Series Code `NY.GDP.TOTL.RT.ZS`
- GDP per capita growth (annual %), Series Code `NY.GDP.PCAP.KD.ZG`

ชื่อไฟล์ครอบคลุมคอลัมน์ปี 1960–2025 แต่สองตัวแปรมีข้อมูลร่วมจริงในช่วง 1970–2021 โปรดเก็บไฟล์ดิบไว้โดยไม่แก้ไข สคริปต์จะคัดรหัสประเทศ/เขตเศรษฐกิจและจัดรูปแบบสำหรับวิเคราะห์เอง

แหล่งดาวน์โหลด: [World Development Indicators](https://databank.worldbank.org/source/world-development-indicators). WDI ระบุใบอนุญาต CC BY 4.0; เมื่อนำข้อมูลไปใช้ให้ให้เครดิต World Bank และระบุว่าโครงงานคัดกรอง จัดรูปแบบ และวิเคราะห์ข้อมูลใหม่
