# Raw source files

These workbooks are the World Bank World Development Indicators (WDI) snapshots used by this project. Keep the originals unchanged so processed outputs can be regenerated and compared with the source.

| File | Contents |
|---|---|
| `data.xlsx` | Resource-rent categories, growth outcomes, poverty, Gini, and political stability |
| `adddata.xlsx` | GDP per capita at constant 2015 US$, population growth, gross capital formation, and trade |

The downloaded files cover 2000–2021. WDI is available through [World Bank DataBank](https://databank.worldbank.org/source/world-development-indicators) and the [World Bank Data Catalog](https://datacatalog.worldbank.org/search/dataset/0037712/world-development-indicators). The Data Catalog lists CC BY 4.0. Please retain attribution to the World Bank and note that this project reshapes, filters, merges, and analyzes the downloaded data.
